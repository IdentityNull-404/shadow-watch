03 / CONNECTION MATRIX

Correlation ≠ attribution

Close timing merits investigation, not an automatic conclusion about a shared attacker.

SUPPORTED CONNECTION

Optimizely → customer websites

Infected third-party scripts provide a common supply-chain delivery path among affected sites.

SYSTEM DEPENDENCY

Chase → other institutions

Shared transaction flows can propagate downstream disruptions, even when only one processing system fails.

NOT ESTABLISHED

One actor → every outage

No publicly validated common malicious infrastructure, indicators or exploit chain currently establish this hypothesis.

Investigative signals: shared indicators of compromise, vendor relationships, malware hashes, authentication events, confirmed attack timelines and independent forensic findings.

04 / TRANSPARENCY

Methodology

CURATED VS AUTOMATED

The incident ledger requires review. Live feed entries are automatically sourced, but are not classified as verified attacks.

OUTAGES ARE NOT ATTACKS BY DEFAULT

An outage records disruption. Calling it an intrusion requires evidence of unauthorized malicious activity.

HOURLY CHECKS

A GitHub Actions workflow refreshes feeds on a scheduled basis when enabled. Runs can be delayed or fail; check the displayed refresh timestamp.

LIMITATIONS

Open-source reporting is not privileged access to forensic logs. Unknown causes remain unknown until independently supported.
